# CPP-03 · Inheritance

Base and derived robot classes that illustrate inheritance in C++98. Each exercise has its own Makefile.

## Exercises

| Directory | Exercise | Focus |
| --- | --- | --- |
| [ex00](./ex00) | ClapTrap | Define the base robot and its actions. |
| [ex01](./ex01) | ScavTrap | Extend the base robot with derived behavior. |
| [ex02](./ex02) | FragTrap | Add a second derived robot type. |

## Build and run

Run these commands from the repository root with a C++98 compatible compiler and Make.

```sh
make -C ex00
./ex00/claptrap
```

To build another exercise, pass its directory to `make -C`.
